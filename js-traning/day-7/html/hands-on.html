Day 7 — Arrays

Hands-on

Task 1 Cart manipulation
  • Start with const cart = ["bread", "milk", "eggs"];
  • Use push to add "butter", then unshift to add "rice" at the start. Log the cart.
  • Use pop to remove the last item. Log what was removed and the new cart.
  • Use splice(1, 1) to remove one item at index 1. Log the cart afterward.
const cart = ["bread", "milk", "eggs"];
cart.push("butter");
cart.unshift("rice");
console.log(cart);

const removed = cart.pop();
console.log(removed, cart);

cart.splice(1, 1);
console.log(cart);

Reference: ../js/hands-on.js (loaded below). Open DevTools → Console.

Task 2 Filter passing scores
  • const scores = [88, 42, 75, 60, 91, 39, 55, 70];
  • filter → new array of scores >= 60. Log it.
  • find → the first failing score (< 60). Log it.
  • every → are all passing? Log the boolean.
  • Bonus: some → is any score above 90?
const scores = [88, 42, 75, 60, 91, 39, 55, 70];
const passing = scores.filter((s) => s >= 60);
const firstFail = scores.find((s) => s < 60);
console.log(passing, firstFail, scores.every((s) => s >= 60));
console.log(scores.some((s) => s > 90));

Reference: ../js/hands-on.js.

Task 3 Map prices with GST
  • const prices = [100, 250, 500, 1200, 80];
  • Use map so each value includes 18% GST (multiply by 1.18). Log original and new array — original unchanged.
  • Bonus: round with .toFixed(2) (returns a string; wrap with Number(...) if you want numbers).
const prices = [100, 250, 500, 1200, 80];
const withGst = prices.map((p) => p * 1.18);
console.log(prices, withGst);
const rounded = prices.map((p) => Number((p * 1.18).toFixed(2)));
console.log(rounded);

Reference: ../js/hands-on.js.

Bonus Reduce — total, max, filter + reduce
  • const expenses = [250, 800, 120, 50, 1500, 75];
  • reduce → total of all expenses.
  • reduce → highest single expense.
  • Bonus: chain filter + reduce to total only expenses > 100.
const expenses = [250, 800, 120, 50, 1500, 75];
const total = expenses.reduce((sum, n) => sum + n, 0);
const max = expenses.reduce((m, n) => (n > m ? n : m), expenses[0]);
const bigSum = expenses
  .filter((n) => n > 100)
  .reduce((sum, n) => sum + n, 0);
console.log(total, max, bigSum);

Reference: ../js/hands-on.js.
