Day 7 — Arrays

Lesson

1 Creating & accessing

Index from 0, use .length, last element via arr[arr.length - 1] or arr.at(-1). Bracket notation with a negative number is not “from the end” — it is a normal key, so you get undefined.

const fruits = ["apple", "banana", "mango"];
console.log(fruits[0]);
console.log(fruits[fruits.length - 1]);
fruits[1] = "cherry";
console.log(fruits[-1]);    // undefined
console.log(fruits.at(-1)); // "mango"

Runs in ../js/lesson.js. Open the console (F12).

2 Mutating methods

push/pop at the end; unshift/shift at the start. splice removes or inserts in place.

const cart = ["apple", "banana"];
cart.push("mango");
cart.pop();
cart.unshift("orange");
cart.shift();

const items = ["a", "b", "c", "d"];
items.splice(1, 2); // remove 2 at index 1

const more = ["a", "b", "c"];
more.splice(1, 0, "X", "Y"); // insert at 1, delete 0

Same file: ../js/lesson.js.

3 Non-mutating methods

slice copies a range into a new array. splice mutates — one letter, opposite worlds.

const arr = [1, 2, 3, 4, 5];
arr.slice(1, 3);
arr.concat([6, 7]);
arr.join("-");
arr.includes(3);
arr.indexOf(4);
// arr unchanged

Same file: ../js/lesson.js.

4 forEach & map

forEach runs a function on each element; return value is undefined (side effects). map returns a new array of transformed values.

const numbers = [1, 2, 3, 4];
numbers.forEach(n => console.log(n * 2));
const doubled = numbers.map(n => n * 2);
const withGst = [100, 200, 300].map(p => p * 1.18);

Same file: ../js/lesson.js.

5 filter, find, some, every

Predicate callbacks return booleans. filter keeps all matches; find returns the first match or undefined.

const scores = [88, 42, 75, 60, 91, 39];
scores.filter(s => s >= 60);
scores.find(s => s < 60);
scores.some(s => s < 60);
scores.every(s => s >= 60);

Same file: ../js/lesson.js.

6 reduce — aggregation

arr.reduce((acc, current) => nextAcc, startingValue) folds the array into one value.

const nums = [1, 2, 3, 4, 5];
const sum = nums.reduce((acc, n) => acc + n, 0);
const max = nums.reduce((a, n) => (n > a ? n : a), -Infinity);

Same file: ../js/lesson.js.

7 Spread ...

Copy [...a], merge [...a, ...b], or pass elements as arguments: Math.max(...nums).

const a = [1, 2, 3];
const b = [4, 5, 6];
[...a];
[...a, ...b];
[...a, 99, ...b];
Math.max(...a);

Same file: ../js/lesson.js.
