Task 1 Greetings with map
  • Given ["Priya", "Aarav", "Riya"], use map to build a new array of strings like "Hello, Priya", etc.
const names = ["Priya", "Aarav", "Riya"];
const greetings = names.map((name) => `Hello, ${name}`);
console.log(greetings);

Task 2 Evens, then sum with reduce
  • Start from an array of numbers. Use filter to keep only even values, then reduce to sum them.
const nums = [1, 2, 3, 4, 5, 6, 7, 8];
const evenSum = nums
  .filter((n) => n % 2 === 0)
  .reduce((sum, n) => sum + n, 0);
console.log(evenSum);

Reference: ../js/homework.js.

Task 3 Maximum two ways
  • Given [3, 1, 4, 1, 5, 9, 2, 6], find the maximum using Math.max(...arr) and again using reduce.
const arr = [3, 1, 4, 1, 5, 9, 2, 6];
const maxSpread = Math.max(...arr);
const maxReduce = arr.reduce((max, n) => (n > max ? n : max), arr[0]);
console.log(maxSpread, maxReduce);

Reference: ../js/homework.js.

Task 4 Average of an array
  • Write a function that takes any numeric array and returns its average: sum / length.
function average(arr) {
  const sum = arr.reduce((total, n) => total + n, 0);
  return sum / arr.length;
}
