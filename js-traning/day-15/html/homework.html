Task 1 Predict the this Output
  • Create an object with a greet() method.
  • Call the method in different ways.
  • Observe how this changes. 
const user = {

  name: "Priya",

  greet() {

    console.log(this.name);
  }
};

user.greet();

const fn =

  user.greet;

fn();

user.greet.call({

  name: "X"
});
// Output:
//
// Priya
//
// undefined
//
// X
//
// user.greet():
// this refers to user.
//
// fn():
// function lost its object context.
//
// call():
// manually sets this.

Try the steps, then compare with ../js/homework.js.

Task 2 Fix Callback Bugs Three Ways
  • Fix a callback losing this.
  • Use bind, arrow wrapper, and class field arrow.
  • Compare all three approaches. 
// bind()

class TimerA {

  constructor() {

    this.sec = 0;
  }

  tick() {

    this.sec++;

    console.log(this.sec);
  }
}

const a =

  new TimerA();

setInterval(

  a.tick.bind(a),

  1000
);
// arrow wrapper

class TimerB {

  constructor() {

    this.sec = 0;
  }

  tick() {

    this.sec++;

    console.log(this.sec);
  }
}

const b =

  new TimerB();

setInterval(() => {

  b.tick();

}, 1000);
// class field arrow

class TimerC {

  sec = 0;

  tick = () => {

    this.sec++;

    console.log(this.sec);
  };
}

const c =

  new TimerC();

setInterval(

  c.tick,

  1000
);
// All three fixes preserve
// the correct this binding.

Task 3 Use apply() with sum()
  • Create a sum() function using rest parameters.
  • Call it using .apply().
  • Understand why apply() is useful. 
function sum(...nums) {

  return nums.reduce(

    (a, b) => a + b,

    0
  );
}

const values =

  [1, 2, 3, 4, 5];

console.log(

  sum.apply(null, values)
);
// Output:
//
// 15
//
// apply() shines when
// arguments already exist
// inside an array.

Task 4 bind() with Arrow Functions
  • Create a top-level arrow function.
  • Try rebinding it using bind().
  • Observe lexical this. 
const f = () => {

  console.log(this);
};

const bound =

  f.bind({

    x: 1
  });

bound();
// Output:
//
// Global object or undefined
// depending on environment.
//
// Arrow functions do not
