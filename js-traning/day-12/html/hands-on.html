Day 12 — Error Handling & Module Basics

Hands-on

Open DevTools → Console. Tasks 1–3 are in ../js/hands-on.js. Bonus ES modules: ../js/mathUtils.js + ../js/app.js (loaded with type="module").

1 Safe JSON.parse — safeParse(str)

try / catch around JSON.parse(str). On success return the value; on failure log Invalid JSON: plus err.message and return null. Test with a valid string and a broken one.

function safeParse(str) {
  try {
    return JSON.parse(str);
  } catch (err) {
    console.log("Invalid JSON:", err.message);
    return null;
  }
}

Reference: ../js/hands-on.js

2 setAge(age) — throw Error, wrap in try/catch

Throw new Error("Age must be a number") if typeof age !== "number". Throw new Error("Age must be 0–120") if out of range. Otherwise return age. Test 25, "twenty", 200.

function setAge(age) {
  if (typeof age !== "number") throw new Error("Age must be a number");
  if (age < 0 || age > 120) throw new Error("Age must be 0–120");
  return age;
}

Reference: ../js/hands-on.js

3 ValidationError + validateEmail

Subclass Error, set this.name = "ValidationError". validateEmail throws if @ is missing. In catch, branch on err instanceof ValidationError.

class ValidationError extends Error {
  constructor(message) {
    super(message);
    this.name = "ValidationError";
  }
}
function validateEmail(email) {
  if (!email.includes("@")) throw new ValidationError("Invalid email");
  return email;
}

Reference: ../js/hands-on.js
