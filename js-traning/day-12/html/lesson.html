Day 12 — Error Handling & Module Basics

Lesson

1 Error types: syntax, runtime, logic

Syntax — at parse time; the file cannot run (e.g. missing bracket). Runtime — while running; try/catch can handle (e.g. null.foo). Logic — code runs but the answer is wrong; fix with tests, not catch.

// Logic bug — runs, wrong answer
const average = (a, b) => a + b / 2; // should be (a + b) / 2

Run ../js/lesson.js (browser console or node day-12/js/lesson.js).

2 try / catch / finally

try holds risky code; catch (err) runs if an error is thrown; finally runs whether or not there was an error.

try {
  JSON.parse("{bad");
} catch (e) {
  console.log("oops");
}
console.log("done");

Same: ../js/lesson.js.

3 The Error object

err.message, err.name (TypeError, SyntaxError, …), err.stack. Branch on err.name or instanceof when you need different recovery paths.

try {
  null.foo;
} catch (err) {
  console.log(err.message, err.name);
}

Same: ../js/lesson.js.

4 throw new Error(...)

Throw an Error instance (not a bare string) so callers get message, name, and stack.

if (b === 0) throw new Error("Cannot divide by zero");

Same: ../js/lesson.js (divide example).

5 Custom error classes

class ValidationError extends Error — set this.name in the constructor; use err instanceof ValidationError in catch. Re-throw with throw err when it is not yours to handle.

class ValidationError extends Error {
  constructor(message) {
    super(message);
    this.name = "ValidationError";
  }
}

Same: ../js/lesson.js.

6 Modules — named export / import

Named exports: export function add() {}, export { multiply }. Import: import { add, PI } from "./mathUtils.js", import * as math from "./mathUtils.js", import { add as sum } from "./mathUtils.js".

Source: ../js/mathUtils.js + ../js/day12-lesson-modules.mjs (loaded below). If imports fail from file://, serve the folder with a local static server.

7 Default export & mixing with named

export default function greet(name) {} — import without braces: import greet from "./greet.js". Mix: import formatPrice, { TAX } from "./priceUtils.js".

Source: ../js/greet.js, ../js/priceUtils.js, ../js/day12-lesson-modules.mjs.
