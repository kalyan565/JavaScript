Day 8 — Objects

Lesson

1 Object literals

Syntax: const obj = { key1: value1, key2: value2 }. Values can be strings, numbers, booleans, arrays, nested objects, or functions.

const userNested = {
  name: "Priya",
  age: 24,
  city: "Jaipur",
  isActive: true,
  hobbies: ["reading", "trekking"],
  address: {
    street: "MI Road",
    pincode: "302001",
  },
};
console.log(userNested);

Runs in ../js/lesson.js. Open the console (F12).

2 Dot vs bracket

Dot (user.name) is the default. Use brackets for dynamic keys (user[field]) or keys with spaces (user["favourite color"]). Missing properties are undefined.

const user = { name: "Priya", age: 24, "favourite color": "blue" };
console.log(user.name);
console.log(user["favourite color"]);
const field = "name";
console.log(user[field]);
console.log(user.email);

const u = { name: "Priya" };
console.log(u.name);
const f = "name";
console.log(u[f]);
console.log(u.email);

Same file: ../js/lesson.js.

3 Add, update, delete

const locks the binding to the object, not the contents inside the object. You can still add, change, and remove properties.

const userMutable = { name: "Priya", age: 24 };
userMutable.email = "priya@example.com";
userMutable.city = "Jaipur";
userMutable.age = 25;
delete userMutable.city;

console.log(userMutable);

Same file: ../js/lesson.js.

4 Methods and this

A property whose value is a function is a method. Inside a normal method, this is the object the method was called on. Prefer greet() { } shorthand — avoid arrow functions as methods (they do not get their own this).

const userMethods = {
  name: "Aarav",
  age: 22,
  greet() {
    return `Hello, I am ${this.name}`;
  },
  birthday() {
    this.age += 1;
    return `Happy birthday! ${this.name} is now ${this.age}`;
  },
};

console.log(userMethods.greet());
console.log(userMethods.birthday());
console.log(userMethods.age);

Same file: ../js/lesson.js.

5 Destructuring

Pull properties into variables: const { name, age } = user;. Rename with name: userName, defaults with phone = "N/A", and use the same pattern in function parameters.

const userFull = {
  name: "Riya",
  age: 23,
  city: "Jaipur",
  email: "r@x.in",
};

const { name, age } = userFull;
const { name: userName, city } = userFull;
const { phone = "N/A" } = userFull;

const greet = ({ name: n, age: a }) => `Hi ${n}, age ${a}`;
console.log(greet(userFull));

Same file: ../js/lesson.js (also includes follow-along u2).

6 Object.keys, values, entries

Turn property names, values, or [key, value] pairs into arrays — then chain map, forEach, etc.

const userKeys = { name: "Anaya", age: 21, city: "Jaipur" };

console.log(Object.keys(userKeys));
console.log(Object.values(userKeys));
console.log(Object.entries(userKeys));

Object.entries(userKeys).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});

Same file: ../js/lesson.js.

7 Object.assign and spread

Merge or shallow-copy objects: Object.assign({}, a, b) or { ...a, ...b }.

const objA = { name: "Priya" };
const objB = { age: 24 };

const merged = Object.assign({}, objA, objB);
const merged2 = { ...objA, ...objB };
const copy = { ...objA };

console.log(merged, merged2, copy);

Same file: ../js/lesson.js.
