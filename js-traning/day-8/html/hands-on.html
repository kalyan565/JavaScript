Hands-on

Task 1 Build a student object
  • Properties: name = "Anaya", age = 21, city = "Jaipur", course = "B.Tech", marks (array of 3 numbers).
  • Log the student, then log name, age, and the first mark using dot notation.
  • Add email = "anaya@example.com", set age to 22, delete city, and log the object again.
const student = {
  name: "Anaya",
  age: 21,
  city: "Jaipur",
  course: "B.Tech",
  marks: [85, 90, 88],
};

console.log(student);
console.log(student.name, student.age, student.marks[0]);

student.email = "anaya@example.com";
student.age = 22;
delete student.city;

console.log(student);

Task 2 bankAccount methods and this
  • holder = "Aarav", balance = 5000.
  • deposit(amount) adds to balance and returns the new balance.
  • withdraw(amount) subtracts only if the balance is enough; otherwise return "Insufficient funds".
  • Test: deposit 1000, withdraw 2000, withdraw 10000.
const bankAccount = {
  holder: "Aarav",
  balance: 5000,
  deposit(amount) {
    this.balance += amount;
    return this.balance;
  },
  withdraw(amount) {
    if (this.balance >= amount) {
      this.balance -= amount;
      return this.balance;
    }
    return "Insufficient funds";
  },
};

console.log(bankAccount.deposit(1000));
console.log(bankAccount.withdraw(2000));
console.log(bankAccount.withdraw(10000));

Same code runs from ../js/hands-on.js.

Task 3 Destructuring product
  • Object: { id: 101, name: "Laptop", price: 60000, brand: "Dell", stock: 5 }.
  • Destructure name and price; log them.
  • Destructure brand renamed to make; log it.
  • Destructure warranty with default "1 year" (property missing); log it.
const product = {
  id: 101,
  name: "Laptop",
  price: 60000,
  brand: "Dell",
  stock: 5,
};

const { name, price } = product;
console.log(name, price);

const { brand: make } = product;
console.log(make);

const { warranty = "1 year" } = product;
console.log(warranty);

Same code runs from ../js/hands-on.js.

Bonus Keys, values, entries, count
  • Use the student object from Task 1 (after edits).
  • Log all keys with Object.keys, all values with Object.values.
  • Use Object.entries with forEach to log each line as key: value.
  • Bonus: count how many properties the object has.
console.log(Object.keys(student));
console.log(Object.values(student));
Object.entries(student).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
console.log(Object.keys(student).length);
