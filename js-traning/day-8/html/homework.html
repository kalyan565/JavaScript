Day 8 — Objects

Homework

1 book and bracket notation
  • Create book with title, author, year, and pages.
  • Log the title using bracket notation with a variable holding the key name (e.g. const k = "title"; book[k]).

Reference: ../js/homework.js. Open the console.

2 summary() method
  • Add a method summary() that returns "<title> by <author> (<year>)" using a template literal and this.

Reference: ../js/homework.js.

3 Object.entries + forEach
  • Use Object.entries and forEach to print every property of any object you choose.

Reference: ../js/homework.js.

4 Spread copy
  • Copy an object with the spread operator, change something on the copy, and confirm the original is unchanged.

Reference: ../js/homework.js.
