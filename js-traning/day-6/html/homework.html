Task 1 kmToMiles(km)
  • Return distance in miles: km * 0.621.
function kmToMiles(km) {
  return km * 0.621;
}

Reference solution in ../js/homework.js (loaded below). Open the console to see sample calls.

Task 2 gstAmount(price, rate = 18)
  • Return the tax amount for price at rate percent.
  • Use default parameter rate = 18 when the caller omits rate.
function gstAmount(price, rate = 18) {
  return (price * rate) / 100;
}

Same script in ../js/homework.js.

Task 3 fullName(first, last)
  • Return the full name as a single string (e.g. first and last separated by a space).
function fullName(first, last) {
  return `${first} ${last}`;
}

Task 4 isAdult(age)
  • Return true if age is 18 or older, otherwise false.
function isAdult(age) {
  return age >= 18;
