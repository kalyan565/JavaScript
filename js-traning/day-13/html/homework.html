Day 13 — Execution Context & Hoisting

Homework

Task 1 Predict typeof with var Hoisting
  • Predict the output before running the code.
  • Observe how typeof behaves with hoisted variables. 
console.log(typeof age);

var age = 25;
// Output:
//
// undefined
//
// var declarations are hoisted
// and initialized as undefined.
//
// typeof undefined returns
// the string "undefined".

Task 2 Access let Before Declaration
  • Access a let variable before declaration.
  • Observe the TDZ error.
  • Identify the exact error type. 
console.log(city);

let city = "Jaipur";
// Error:
//
// ReferenceError:
// Cannot access 'city'
// before initialization
//
// let variables stay inside
// the Temporal Dead Zone (TDZ)
// until initialized.

Try the steps, then compare with ../js/homework.js.

Task 3 Function Declaration vs Expression vs Arrow
  • Compare hoisting behavior of different function styles.
  • Call each function before declaration.
  • Observe TypeError and ReferenceError behavior. 
// Function Declaration

sayHello();

function sayHello() {

  console.log("Hello");
}


// Function Expression

greet();

var greet = function () {

  console.log("Hi");
};


// Arrow Function

welcome();

const welcome = () => {

  console.log("Welcome");
};
// Output:
//
// Hello
//
// TypeError:
// greet is not a function
//
// ReferenceError:
// Cannot access 'welcome'
// before initialization
//
// Function declarations are
// fully hoisted.
//
// var expressions are hoisted
// as undefined.
//
// const arrow functions remain
// in the TDZ until initialized.

Try the steps, then compare with ../js/homework.js.

Task 4 Read the Stack Trace
  • Add console.trace() inside a function.
  • Run the program and inspect the stack trace.
  • Identify each Execution Context (EC). 
function third() {

  console.trace();
}

function second() {

  third();
}

function first() {

  second();
}

first();
// Stack Trace:
//
// third()
//
// second()
//
// first()
//
// Global Execution Context
//
// Each function call creates
// a new Execution Context (EC)
// and pushes it onto the stack.

Try the steps, then compare with ../js/homework.js.
