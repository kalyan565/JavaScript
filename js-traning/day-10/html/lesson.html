Day 10 — DOM Manipulation Basics

Lesson

1 What is the DOM?

The browser parses your HTML and builds a tree of objects in memory. That tree is the Document Object Model (DOM). JavaScript reads and updates that tree; the browser re-renders. The entry point is document.

// Conceptual tree:
// document
//   └── html
//         └── body
//               ├── h1#title
//               └── button.btn

console.log(document.documentElement);

../js/lesson.js injects a small demo box at the bottom of the page, then runs the topics. Open the console (F12). In Node, the script only logs that you need a browser.

2 Selecting elements

Prefer querySelector / querySelectorAll (CSS selectors). querySelectorAll returns a NodeList — forEach works; use [...nodeList] if you need map / filter.

document.getElementById("day10-title");
document.querySelector(".btn");
document.querySelectorAll(".btn");
[...document.querySelectorAll(".btn")];

Same file: ../js/lesson.js (queries are scoped to the injected sandbox where noted).

3 textContent vs innerHTML

textContent is plain text — tags show as characters (safe). innerHTML parses HTML — never assign untrusted user input (XSS risk).

el.textContent = "<em>Hi</em>"; // shows angle brackets
el.innerHTML = "<em>Hi</em>";     // renders emphasis

Same file: ../js/lesson.js.

4 Styles and classList

Inline: el.style.color (camelCase for CSS properties). Prefer classes in CSS and classList.add / remove / toggle / contains from JS.

title.style.color = "red";
title.style.backgroundColor = "yellow";
title.classList.add("highlight");
title.classList.toggle("active");

Same file: ../js/lesson.js.

5 Creating elements

document.createElement → set textContent / attributes / classes → appendChild, prepend, or append. Nothing appears until it is inserted.

const li = document.createElement("li");
li.textContent = "Buy milk";
li.classList.add("todo-item");
list.appendChild(li);
list.prepend(anotherLi);

Same file: ../js/lesson.js.

6 Removing elements

element.remove() removes a node from its parent. Clearing children with parent.innerHTML = "" is quick but not always ideal.

const li = document.querySelector("#todo-1");
li.remove();

list.innerHTML = "";

Same file: ../js/lesson.js (uses #day10-todo-1 in the demo).
