Day 10 — DOM Manipulation Basics

Hands-on

Task 1 Select and change text
  • Use document.querySelector to grab #title.
  • Set textContent to Hello, <your name>!
  • Set style.color to "crimson".
  • Bonus: set style.fontFamily to "Georgia, serif".
const title = document.querySelector("#title");
title.textContent = "Hello, Kalyan!";
title.style.color = "crimson";
title.style.fontFamily = "Georgia, serif";

Reference: ../js/hands-on.js (loaded at the bottom). The live HTML is in the box below.

Task 2 Toggle dark theme
  • Grab #theme-btn (events come on Day 11 — for now the script runs the toggle at the bottom).
  • Call document.body.classList.toggle("dark") twice and watch the page flip.
  • Bonus: log document.body.classList.contains("dark").
const themeBtn = document.querySelector("#theme-btn");
document.body.classList.toggle("dark");
document.body.classList.toggle("dark");
console.log(document.body.classList.contains("dark"));

Same file: ../js/hands-on.js.

Task 3 Build a list dynamically
  • const names = ["Priya", "Aarav", "Riya", "Kabir"];
  • Grab #names-list. For each name: create <li>, set textContent, add class name-item, appendChild to the list.
  • Bonus: template literal `${index + 1}. ${name}`.
names.forEach((name, index) => {
  const li = document.createElement("li");
  li.textContent = `${index + 1}. ${name}`;
  li.classList.add("name-item");
  nameList.appendChild(li);
});

Same file: ../js/hands-on.js.

Bonus Build a card
  • In #cards, build a <div class="card"> from product: <h3> name, <p> brand, <span> price as ₹60000.
const product = { name: "Laptop", price: 60000, brand: "Dell" };
const priceSpan = document.createElement("span");
priceSpan.textContent = `₹${product.price}`;

Same file: ../js/hands-on.js.
