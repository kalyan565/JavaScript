Day 16 — Prototypes & the Prototype Chain

Hands-on

Task 1 Inspect a Prototype
  • Inspect the prototype chain of an array.
  • Use Object.getPrototypeOf().
  • Identify where the chain ends. 
const arr = [1, 2, 3];

console.log(

  Object.getPrototypeOf(arr)
);

console.log(

  Object.getPrototypeOf(

    Object.getPrototypeOf(arr)
  )
);

console.log(

  Object.getPrototypeOf(

    Object.getPrototypeOf(

      Object.getPrototypeOf(arr)
    )
  )
);
// Output:
//
// Array.prototype
//
// Object.prototype
//
// null
//
// Prototype Chain:
//
// arr
// ↓
// Array.prototype
// ↓
// Object.prototype
// ↓
// null

Task 2 Build with Object.create()
  • Create inherited objects using Object.create().
  • Share methods through prototypes.
  • Compare own vs inherited properties. 
const vehicle = {

  start() {

    console.log(

      `${this.name} starting`
    );
  }
};

const car =

  Object.create(vehicle);

car.name = "Tata Nexon";

const bike =

  Object.create(vehicle);

bike.name = "Royal Enfield";

car.start();

bike.start();

console.log(

  car.hasOwnProperty("name")
);

console.log(

  car.hasOwnProperty("start")
);

console.log(

  "name" in car
);

console.log(

  "start" in car
);
// Output:
//
// Tata Nexon starting
//
// Royal Enfield starting
//
// true
// false
// true
// true
//
// name is an own property.
//
// start is inherited
// from vehicle.

Task 3 Constructor Function Inheritance
  • Create constructor-based inheritance.
  • Inherit using Object.create().
  • Share methods through prototypes. 
function Person(name) {

  this.name = name;
}

Person.prototype.greet =

function () {

  console.log(

    "Hi, I'm " + this.name
  );
};

function Student(name, school) {

  Person.call(this, name);

  this.school = school;
}

Student.prototype =

  Object.create(

    Person.prototype
  );

Student.prototype.study =

function () {

  console.log(

    this.name +

    " studies at " +

    this.school
  );
};

const student =

  new Student(

    "Riya",

    "IIT Delhi"
  );

student.greet();

student.study();
// Output:
//
// Hi, I'm Riya
//
// Riya studies at IIT Delhi
//
// Student inherits
// greet() from Person.

Try the steps, then compare with ../js/hands-on.js.

Bonus hasOwnProperty vs in
  • Compare inherited and own properties.
  • Predict the results before running.
  • Understand hasOwnProperty vs in. 
const dog =

  Object.create({

    species: "Canis"
  });

dog.name = "Bruno";

console.log(

  dog.hasOwnProperty("name")
);

console.log(

  dog.hasOwnProperty("species")
);

console.log(

  "name" in dog
);

console.log(

  "species" in dog
);

console.log(

  "toString" in dog
);
// Output:
//
// true
// false
// true
// true
// true
//
// hasOwnProperty():
// checks only own properties.
//
// in:
// checks both own and
// inherited properties.
