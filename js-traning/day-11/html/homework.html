1 Random RGB background

Button #color-change: on click, set document.body.style.backgroundColor to rgb(r,g,b) using Math.floor(Math.random() * 256) for each channel.

colorBtn.addEventListener("click", () => {
  const r = Math.floor(Math.random() * 256);
  const g = Math.floor(Math.random() * 256);
  const b = Math.floor(Math.random() * 256);
  document.body.style.backgroundColor = `rgb(${r}, ${g}, ${b})`;
});

Reference: ../js/homework.js

2 Live length styling (#less)

On input: background red if fewer than 3 characters, green otherwise.

liveInput.addEventListener("input", (e) => {
  const el = e.target;
  el.style.backgroundColor = el.value.length < 3 ? "red" : "green";
});

Reference: ../js/homework.js

3 Sum form (#sum-form, #below)

Listen for submit on the form, preventDefault, add Number(num1.value) + Number(num2.value), show result in #below.

sumForm.addEventListener("submit", (e) => {
  e.preventDefault();
  const a = Number(num1.value);
  const b = Number(num2.value);
  sumOutput.textContent = `Sum: ${a + b}`;
});

Reference: ../js/homework.js

4 Delegated list + dynamic item (#hw-log-list)

One listener on the list; if e.target.tagName === "LI", console.log(e.target.textContent). Append a sixth <li> with createElement — it should work with the same listener.

logList.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") console.log(e.target.textContent);
});
const sixth = document.createElement("li");
sixth.textContent = "Foxtrot (added dynamically)";
logList.appendChild(sixth);
