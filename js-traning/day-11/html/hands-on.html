1 Click counter (#counter-btn, #count)

Increment on each click; update the span. Bonus: from the 10th click, set the button text to Stop clicking!

const counterBtn = document.querySelector("#counter-btn");
const countSpan = document.querySelector("#count");
let clickCount = 0;
counterBtn.addEventListener("click", () => {
  clickCount += 1;
  countSpan.textContent = String(clickCount);
  if (clickCount >= 10) counterBtn.textContent = "Stop clicking!";
});

2 Live input preview (#live-input, #preview)

Use the input event. Bonus: when empty, show Start typing...

liveInput.addEventListener("input", (e) => {
  const value = e.target.value;
  preview.textContent = value === "" ? "Start typing..." : value;
});

Reference: ../js/hands-on.js

3 Form preventDefault (#reg-form, #welcome)

On submit, preventDefault, read #name-field, set welcome with a template literal. Bonus: empty name → Please enter your name.

regForm.addEventListener("submit", (e) => {
  e.preventDefault();
  const name = nameField.value.trim();
  welcome.textContent =
    name === "" ? "Please enter your name" : `Welcome, ${name}!`;
});

Reference: ../js/hands-on.js

4 Event delegation (#todo-list)

One click on the <ul>; toggle done only when e.target.tagName === "LI". Bonus: createElement("li") + appendChild — still toggles without new listeners.

todoList.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") e.target.classList.toggle("done");
});
const bonusLi = document.createElement("li");
bonusLi.textContent = "Brand new task";
todoList.appendChild(bonusLi);
