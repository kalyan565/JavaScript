Day 11 — Events & Event Handling

Lesson

1 addEventListener

Pattern: element.addEventListener("eventName", fn). You can attach multiple listeners. To removeEventListener, pass the same function reference — use a named function, not a one-off arrow you cannot remove later.

btn.addEventListener("click", () => { /* ... */ });
btn.addEventListener("click", namedFn);
btn.removeEventListener("click", namedFn);

../js/lesson.js appends a demo section to body and wires examples. Use the console (F12).

2 The event object e

e.type, e.target, e.target.value (inputs), e.key (keyboard), e.clientX / e.clientY (mouse).

btn.addEventListener("click", (e) => {
  console.log(e.type, e.target, e.clientX, e.clientY);
});
input.addEventListener("input", (e) => console.log(e.target.value));

Same file: ../js/lesson.js.

3 preventDefault

Cancels default behaviour: form submit / full reload, link navigation, context menu, etc.

form.addEventListener("submit", (e) => {
  e.preventDefault();
});
link.addEventListener("click", (e) => e.preventDefault());

Same file: ../js/lesson.js.

4 Mouse events

click, dblclick, mouseover, mouseout, contextmenu (right-click).

box.addEventListener("click", () => {});
box.addEventListener("contextmenu", (e) => e.preventDefault());

Same file: ../js/lesson.js.

5 Keyboard: input vs keydown

input fires as the value changes. On keydown, the value can still be the previous character — use input for “what’s in the field now”. Ctrl+S often needs preventDefault to override the browser save shortcut.

input.addEventListener("keydown", (e) => {
  if (e.key === "Enter") { /* ... */ }
});
document.addEventListener("keydown", (e) => {
  if (e.ctrlKey && e.key === "s") e.preventDefault();
});

Same file: ../js/lesson.js.

6 Bubbling & event delegation

Events bubble up through ancestors. Attach one listener on a parent and inspect e.target — works for children added later.

list.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    e.target.classList.toggle("done");
  }
});

Same file: ../js/lesson.js.
