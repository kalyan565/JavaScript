Homework

Task 1 Template literal from an object
  • Use { first: "Priya", last: "Sharma", city: "Jaipur" } and a template literal to print Priya Sharma from Jaipur.
const person = { first: "Priya", last: "Sharma", city: "Jaipur" };
const { first, last, city } = person;
console.log(`${first} ${last} from ${city}`);

Reference: ../js/homework.js. Open the console (F12).

Task 2 Array destructuring + rest
  • Split [1, 2, 3, 4, 5, 6] into head and ...tail. Log both.
const nums = [1, 2, 3, 4, 5, 6];
const [head, ...tail] = nums;
console.log(head, tail);

Reference: ../js/homework.js.

Task 3 multiply(...nums)
  • Use rest parameters and reduce to multiply any number of arguments.
function multiply(...nums) {
  return nums.reduce((acc, n) => acc * n, 1);
}

Reference: ../js/homework.js (includes sample calls). With no arguments, reduce on an empty array returns the initial value 1 (empty product).

Task 4 Object spread without mutating
  • Use object spread to change one property on a new object and verify the original is unchanged.
const user = { name: "Aarav", age: 21, city: "Delhi" };
const updatedUser = { ...user, age: 22 };
console.log(user);
console.log(updatedUser);

Reference: ../js/homework.js.
