Day 9 — ES6+ Essentials

Hands-on

Task 1 Template literal sentence builder
  • Declare item, price, tax as given in the doc.
  • Build the sentence with a template literal. Compute GST and total inside ${...} (no separate gst / total variables first).
  • Bonus: a multiline template with each part on its own line.
const item = "Laptop";
const price = 60000;
const tax = 0.18;

const sentence = `The ${item} costs ₹${price} + ₹${Math.round(price * tax)} GST = ₹${Math.round(price + price * tax)}.`;
console.log(sentence);

Full solution in ../js/hands-on.js. Open the console (F12).

Task 2 Array + object destructuring
  • From scores: first two into top and second, rest into others.
  • From user: name, rename age to userAge, nested city. Log everything.
const scores = [88, 75, 92, 60, 45];
const [top, second, ...others] = scores;

const user = {
  name: "Anaya",
  age: 21,
  address: { city: "Jaipur", pincode: "302001" },

const { name, age: userAge, address: { city } } = user;

Task 3 Rest parameters
  • sumAll(...numbers) — test (1,2,3), (10,20,30,40), and ().
  • joinNames(separator, ...names) — test joinNames(", ", "Priya", "Aarav", "Riya").
function sumAll(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}

function joinNames(separator, ...names) {
  return names.join(separator);
}

Same file: ../js/hands-on.js.

Bonus Spread to merge settings
  • Merge defaults and userPrefs with object spread so prefs override; keep other defaults.
  • Bonus: applyPrefs(defaults, prefs) that returns { ...defaults, ...prefs }.
const defaults = { theme: "light", lang: "en", notifications: true };
const userPrefs = { theme: "dark", fontSize: 16 };

const mergedSettings = { ...defaults, ...userPrefs };

function applyPrefs(defaultsObj, prefs) {
  return { ...defaultsObj, ...prefs };
}
