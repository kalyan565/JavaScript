Day 9 — ES6+ Essentials

Lesson

1 Template literals

Use backticks for ${expression} interpolation, multiline text without \n, and embedded expressions (ternaries, math, function calls).

const personName = "Priya";
const personAge = 24;
const msg = `Hello, ${personName}. You are ${personAge} years old.`;

const address = `MI Road
Jaipur 302001`;

const taxed = `₹${(1000 * 1.18).toFixed(2)}`;

Runs in ../js/lesson.js. Open the console (F12). (Script uses personName / personAge so it does not clash with window.name in the browser.)

2 Array destructuring

Unpack by position: skip slots with commas, supply defaults, swap with [x, y] = [y, x], gather the rest with ...tail.

const colors = ["red", "green", "blue"];
const [first, second, third] = colors;
const [, , last] = colors;
const [a, b, c, d = "yellow"] = colors;

let x = 1, y = 2;
[x, y] = [y, x];

const [head, ...tail] = [1, 2, 3, 4, 5];

Same file: ../js/lesson.js.

3 Object destructuring (deeper)

Nested: const { address: { city } } = user creates city only. Rename, defaults, ...rest, and destructuring in parameters — often with = {} defaults.

const user = {
  name: "Aarav",
  age: 22,
  address: { city: "Jaipur", pincode: "302001" },
};

const { address: { city } } = user;
const { name: userName, phone = "N/A" } = user;
const { name: onlyName, ...userRest } = user;

const greet = ({ name, age }) => `${name} is ${age}`;
const showInfo = ({ name = "Guest", role = "User" } = {}) =>
  `${role}: ${name}`;

Same file: ../js/lesson.js (see also follow-along u / restU).

4 Rest parameters

Rest collects extra arguments into an array. It must be the last parameter. (Spread expands; rest collects — same ..., different place.)

function sum(...numbers) {
  return numbers.reduce((acc, n) => acc + n, 0);
}

function greet(greeting, ...names) {
  return names.map((n) => `${greeting}, ${n}`).join(" | ");
}

const max = (...n) => Math.max(...n);

Same file: ../js/lesson.js.

5 Spread — arrays and objects

Array spread merges or copies elements. Object spread copies properties; later spreads override earlier keys on conflicts.

const arrA = [1, 2, 3];
const arrB = [4, 5, 6];
console.log([...arrA, ...arrB]);

const profile = { name: "Priya", age: 24, city: "Jaipur" };
const updated = { ...profile, age: 25 };

const defaults = { theme: "light", notifications: true };
const userPrefs = { theme: "dark" };
const finalPrefs = { ...defaults, ...userPrefs };

Same file: ../js/lesson.js.

6 || vs ??

|| falls back when the left side is any falsy value. ?? falls back only for null or undefined — so 0 and "" can be kept.

console.log(0 || "default");
console.log(0 ?? "default");

const userInputCount = 0;
const count = userInputCount ?? 1;

Same file: ../js/lesson.js.

7 Computed property names

Use [expression] as a key inside an object literal instead of assigning after the fact.

const fieldName = "email";
const fieldValue = "priya@x.in";

const user2 = {
  name: "Priya",
  [fieldName]: fieldValue,
  [`is_${fieldName}_verified`]: true,
};

Same file: ../js/lesson.js.
