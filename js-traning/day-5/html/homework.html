Homework

Task 1 FizzBuzz (for loop, 1–50)
  • Print Fizz for multiples of 3, Buzz for multiples of 5, FizzBuzz for both, otherwise the number.
for (let i = 1; i <= 50; i++) {
  if (i % 3 === 0 && i % 5 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}

Task 2 while — smallest n where n² > 1000
  • Start with let n = 1. Increment n while n * n <= 1000.
  • Log n after the loop (expect 32: first integer whose square exceeds 1000).
let n = 1;

while (n * n <= 1000) {
  n++;
}

console.log(n); // 32

Task 3 Nested for — star triangle (5 rows)
  • Outer loop: rows 1–5. Inner loop: append "*" so row i has i stars.
  • Log each row after the inner loop.
for (let i = 1; i <= 5; i++) {
  let row = "";

  for (let j = 1; j <= i; j++) {
    row += "*";
  }

  console.log(row);
}

Same script in ../js/homework.js.

Task 4 Maximum with for...of
  • Given scores, track the largest value using for (const score of scores).
  • Log the maximum (expect 95 for the sample array).
const scores = [88, 72, 95, 60, 41];

let max = scores[0];

for (const score of scores) {
  if (score > max) {
    max = score;
  }
}

console.log(max);
