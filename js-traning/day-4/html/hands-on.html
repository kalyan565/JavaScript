Day 4 — Conditionals and truthy/falsy

Hands-on

Task 1 Grading system
  • Declare const marks = 72 (use a block { ... } if you need to re-run with other values).
  • Use if / else if / else to log a grade: 90+ → "A", 75–89 → "B", 60–74 → "C", below 60 → "F".
  • Test with marks 95, 50, and 75 — confirm each prints the right grade.
  • Bonus: at the top of the chain, if marks are negative or above 100, log "Invalid marks" and do not print a letter grade.
{
  const marks = 72;
  if (marks < 0 || marks > 100) console.log("Invalid marks");
  else if (marks >= 90) console.log(marks, "→ A");
  else if (marks >= 75) console.log(marks, "→ B");
  else if (marks >= 60) console.log(marks, "→ C");
  else console.log(marks, "→ F");
}

Task 2 Day type with switch
  • Declare const day = "Wednesday".
  • Write a switch that logs "Weekday" for Monday–Friday, "Weekend" for Saturday and Sunday, "Invalid day" otherwise.
  • Use intentional fall-through to group weekday cases (no repeated console.log per weekday).
  • Test with "Monday", "Saturday", and "Holiday" (same switch shape in separate blocks, or reassign day if you use let).
{
  const day = "Wednesday";
  switch (day) {
    case "Monday":
    case "Tuesday":
    case "Wednesday":
    case "Thursday":
    case "Friday":
      console.log(day + " → Weekday");
      break;
    case "Saturday":
    case "Sunday":
      console.log(day + " → Weekend");
      break;
    default:
      console.log(day + " → Invalid day");
  }
}

  • For each value, write your guess as a comment, then check with if (value) { ... } else { ... } and log truthy vs falsy.
  • Values: 0, "0", "", " " (single space), null, undefined, NaN, [], {}, "false".
